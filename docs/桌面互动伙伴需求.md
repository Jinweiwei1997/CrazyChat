## 二、桌面 2D 资源（形象）

### 2.1 姿态定义
| 姿态 | 触发 | 表现 |
|------|------|------|
| 静态态 | 空闲、无键盘输入 | 显示静态图 |
| 捕捉态 | 每敲一次键 | 瞬时切到捕捉图后恢复 |

- 过渡：**瞬时切换**（无补间动画）
- 触发：**敲一下切一下**并恢复，非持续保持
- 两图差异不大，捕捉态作为动态反馈

> 缺省默认：捕捉态短促（如 120ms）后回落静态，避免频繁闪烁。

### 2.2 图片来源
- **方案 A（自备）**：用户上传两张图（静态态 + 捕捉态）
- **方案 B（生成）**：只上传一张，系统 AI 生成另一态；生成风格可选：**搞怪 / 唯美**
- 用户后补：可日后补传替换

### 2.3 适配规则
- 组件固定尺寸，上传图**整图等比缩放居中**，超界留白[缺省]
- 不做裁切拉伸，保原图比例

## 三、好友在线发现

| # | 规则 |
|---|------|
| 1 | 无房间：我开游戏，自动发现并展示所有在线好友 |
| 2 | 最多同时展示 **30** 个 |
| 3 | 超 30 自动进麻袋，玩家从麻袋替换上桌 |
| 4 | 组件可**自由拖动**，位置不锁定 |
| 5 | 麻袋存在即显示入口（≥1 好友在线） |
| 6 | 组件/麻袋位置**持久化**，重启恢复 |
| 7 | 好友离线（游戏下线），组件消失；重开游戏恢复 |

## 四、好友组件（单组件结构）

<u>一个好友组件 = 静态图/捕捉图 + 聊天气泡 + 未读红点</u>

### 4.1 组件层级（自下而上）
1. 图片层：静态图 / 捕捉态动画
2. 聊天气泡层：常驻最新消息 或 "..."提示
3. 未读红点层：右上角，示未读数

### 4.2 聊天气泡区域
- **无消息** → 显示 `...` 气泡
- **有消息** → 常驻**最新一条消息**
- 有新消息 → 直接替换，**淡入淡出动效**
- 消息尾缀：可以追加"（未读 n）"计数[缺省]

### 4.3 未读红点
- 右上角红点，显示未读数，"99+"封顶
- 桌面组件**也叠红点**（与气泡并存）

### 4.4 交互状态机（好友组件）
```
[空闲] 静态图
  │ 敲键盘
  ▼
[捕捉] 捕捉图(瞬间) ──→ 回落 [空闲]
  │ 双击Ctrl定位 / 点击气泡
  ▼
[高亮/选中] 虚线框/描边高亮
  │
  ├─ 左右键 ← 切换别的好友
  ├─ Enter → 打开该好友聊天卡
  └─ 点击气泡 → 打开该好友聊天卡
  │
  └── 拖拽 ──→ 移动位置 / 拖入麻袋
```

## 五、麻袋

### 5.1 入口
- 有 ≥1 在线好友即显示麻袋入口（角落，默认在玩家组件旁）
- 可拖拽移动，位置持久化

### 5.2 收纳
- **拖拽**组件进麻袋 → 隐藏该组件
- 被收纳组件**不再渲染捕捉动画**，仅静态图显示于列表
- 超 30 自动收录（无需手动拖）

### 5.3 麻袋列表项（点击麻袋展开）
每项 = **静态图 + 最新一条消息 + 未读条数**
- 无昵称/在线状态等额外信息
- 列表项样式仿微信消息列表
- 麻袋内好友有新消息 → **麻袋入口红点**，引导玩家点开

### 5.4 麻袋交互
- 点列表项：可从麻袋**替换上桌**（需移除桌上另一组件以腾出 30 名额）[缺省]
- 列表项可点开进入聊天[缺省]

## 六、聊天

### 6.1 双触发路径
| 路径 | 操作 | 结果 |
|------|------|------|
| 键盘定位 | 双击 Ctrl → 高亮 → 左右键选目标 → Enter | 打开该好友聊天卡 |
| 鼠标主动 | 点击组件/气泡 | 直接打开聊天卡 |

- 定位意图：让玩家明确 Enter 进的是哪个好友
- 定位优先级：**最新消息 > 老消息 > `...` 气泡**

### 6.2 聊天窗口形态
- **跟随组件的小卡片**（不挡全局）
- 卡片上有入口可打开**全部历史记录**（大窗口）[缺省]

### 6.3 收发消息
- **发**：输入框 → Enter 发送；发送后卡片气泡刷新为最新消息
- **收**：新消息替换气泡（淡入淡出）+ 右上红点未读 +1
- **未读**：累积不设上限，显示封顶 99+
- **离线**：允许发离线消息，对方上线收到
- **云端同步**：历史消息跨设备/重装不丢
- **新消息动效**：淡入淡出

### 6.4 聊天卡状态机
```
[关闭] 仅组件
  │ 点击气泡 / 定位+Enter
  ▼
[卡片开] 跟随组件
  ├─ 有未读 → 显示未读列表（顶格新到）
  ├─ 输入 → Enter 发送
  ├─ 发送 → 清本地该好友未读计数
  ├─ 点"历史"入口 → 打开全量记录
  └─ 关闭 → 回 [关闭]
```

### 6.5 未读清理触发
- 打开卡片 → 清该好友未读
- 红点消失、气泡保留最新消息
