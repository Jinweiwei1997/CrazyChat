# 桌面组件隐身（右键长按）

## 目标

在 CrazyChat 运行期间，通过全局右键长按 3 秒，将桌上游戏组件渐隐并完全隐藏；可通过再次长按或托盘菜单取消隐藏并恢复显示，减少对桌面的视觉干扰。

## 决策基线

### 需求边界

- **触发范围**：只要本游戏进程在跑，即全局监听鼠标右键（不要求 Overlay 焦点或命中游戏 UI）。Windows 下与现有键鼠监听一致，切到其他窗口仍可计时。
- **进入隐身**：按住右键满 3 秒 → 桌上组件完成渐隐并隐藏。长按过程中鼠标旁显示环形进度条 + 文案「隐藏」，颜色随时间填满闭合。
- **中途取消进入**：未满 3 秒松开右键 → 立刻恢复全显示，关闭进度环，渐隐进度清零。
- **隐藏内容**：麻袋、自己与好友桌上头像及其附属 UI（名字、气泡、未读、设置入口、互动环、按键图标、左下状态等桌上游戏组件）。进入隐身时关闭已打开的聊天、设置、动态形象、裁剪等浮层；取消隐藏后不自动重新打开这些面板。
- **取消隐藏（两种）**：
  1. 再次全局右键长按满 3 秒：鼠标旁环形进度 + 文案「取消隐藏」，组件同步 3 秒渐显，满 3 秒完全显示。
  2. Standalone 托盘右键菜单「取消隐藏」：立刻或极短渐显恢复全部桌上组件（不等待 3 秒）。
- **进度 HUD**：仅在长按计时期间显示；跟随鼠标旁；不参与被隐藏的桌上组件集合。
- **持久化**：隐身状态不写入 prefs；每次启动均为显示状态。
- **平台**：Unity Editor Play 与 Windows Standalone 均支持长按隐身/取消隐身；托盘「取消隐藏」仅 Standalone（Editor 无托盘，只能长按取消）。
- **失败 / 干扰**：全局右键可能与系统或其他应用的右键菜单冲突，属已知取舍，不在本需求内消除。隐身逻辑失败不得导致进程退出。
- **明确不做**：跨重启记忆隐身；强制托盘进「显示隐藏的图标」；新 P2P 通道 / 新 Manager / 新 Bootstrap；改 `SteamManager` / Steamworks.NET；给麻袋加玩法；左键或其他键触发隐身。
- **兼容**：装配入口仍为 `OverlayBootstrap` / `FriendOverlayView.Build`；聊天通道 1、互动通道 2；现有托盘「退出」保留；隐身中托盘菜单增加「取消隐藏」。

### 技术决策

- **职责**：Overlay 下新增隐身控制器（如 `OverlayStealthController`）+ 进度 HUD（如 `OverlayStealthHud`）；由 `FriendOverlayView.Build` 或 Bootstrap 接线；不新 Manager / 事件总线。
- **输入**：扩展或复用 `OverlayInputWatcher` / `GetAsyncKeyState` 的右键（VK 0x02）按下时长，暴露「右键按住时长」或边沿事件供隐身使用；避免平行再写一套全局键鼠轮询，除非现有类无法干净扩展。
- **显示**：桌上可隐藏根节点使用统一 `CanvasGroup`（或等价）做 alpha 渐隐/渐显；完全隐藏后应不可交互（alpha 0 且关闭交互 / 或等效），保证桌面点击穿透行为与现有透明窗一致。
- **浮层**：进入隐身时调用现有 Hide/Close 路径关闭聊天、设置等，不另造关闭总线。
- **托盘**：扩展 `OverlayTrayIcon` 菜单：未隐身时保持「退出」；隐身中增加「取消隐藏」并回调隐身控制器恢复显示。
- **文档**：获批实施时更新 `docs/game-ui-rules.md`；不更新 wiki（仓库无 `docs/wiki/`）。

## 设计视图

### 功能设计

1. 用户按住右键：出现跟随鼠标的环形进度与「隐藏」；桌上组件 alpha 随进度从 1→0。
2. 满 3 秒：进入隐身态；进度 HUD 消失；组件保持隐藏且不可点；已开浮层已关闭。
3. 未满松开：alpha 立刻回 1，HUD 消失，不进入隐身态。
4. 隐身态再按住右键：HUD 显示「取消隐藏」，组件 alpha 0→1 随进度；满 3 秒退出隐身态。
5. 隐身态点托盘「取消隐藏」：立即恢复显示并退出隐身态。
6. 进程重启后总是非隐身。

### 技术设计

#### 整体方案

- **输入层**：`OverlayInputWatcher`（或紧邻辅助）提供右键按住计时。
- **状态层**：`OverlayStealthController` 持有 `Visible / Hiding / Hidden / Showing`（或等价）与 3 秒常量；驱动 CanvasGroup 与 HUD。
- **表现层**：`OverlayStealthHud` 画环形填充 + 文案，挂在不被隐身 CanvasGroup 影响的层上。
- **接线**：`FriendOverlayView` 提供可隐藏根与关闭浮层入口；`OverlayTrayIcon` 订阅隐身态刷新菜单。

#### 实现流程

右键按下 → 按当前是否 Hidden 选择「隐藏」或「取消隐藏」模式 → 每帧更新进度与 alpha → 松开则若未完成则立刻复位 Visible → 满 3 秒切 Hidden 或 Visible。托盘「取消隐藏」→ 直接 Visible。

### 预估改动面

- `OverlayInputWatcher`（或同目录输入辅助）、新建隐身控制/HUD、`FriendOverlayView` 接线、`OverlayTrayIcon` 菜单、`docs/game-ui-rules.md`。
- 测试：Editor / Standalone 长按进入与取消；中途松开复位；托盘取消隐藏；浮层关闭；重启不保持隐身。

## 验收

- 游戏在跑、焦点在其他窗口时按住右键满 3 秒 → 桌上组件隐藏，进度环曾显示「隐藏」→ 目视。
- 未满 3 秒松开 → 组件立刻全显示，进度环消失 → 目视。
- 隐身后再长按满 3 秒 → 进度显示「取消隐藏」且渐显恢复 → 目视。
- 隐身中 Standalone 托盘「取消隐藏」→ 立刻恢复显示 → 目视。
- 进入隐身时已打开的聊天/设置被关闭；恢复后不自动打开 → 目视。
- Editor Play 可长按隐身；无托盘项时仍可用长按取消 → 目视。
- 重启后非隐身 → 目视。
- 未新增 Manager / 通道；未改 SteamManager → diff。
- `docs/game-ui-rules.md` 已写隐身规则 → 文档审阅。
