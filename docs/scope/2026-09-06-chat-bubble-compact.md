# 桌上聊天：气泡简版与侧栏全历史

## 目标

桌上好友聊天改为「收起单句气泡 → 头像上方简版会话 → 需要时侧栏看全历史」，减少平时占屏，同时保留连续回复与查旧消息能力。

## 决策基线

### 需求边界

- **对象**：仅桌上好友头像；麻袋条目保持纯展示，不加聊天展开。
- **收起态**：头像上方始终有气泡；有消息时显示最新一句摘要，无消息时显示占位「…」。
- **展开入口**：点气泡、点头像、或定位到该好友后按 Enter → 进入简版展开。
- **简版展开**：头像脸大小不变；在原气泡位置变大。上方为消息列表，下方为简单输入框。列表从「对方最近一条消息」起至当前最新（含你之后的回复）；若对方从未发过，可仅显示输入框（或空列表 + 输入）。
- **简版收起**：再点气泡区域、点关闭、或按 Esc → 回到收起单句气泡；点另一好友的展开入口则切换到该好友简版。
- **全部消息**：简版发送按钮左侧提供入口；打开现有侧栏大面板，展示与该好友的**全部**历史消息；关闭侧栏后回到该好友的简版展开（输入仍可用）。
- **连续输入**：简版打开期间发送后保持可继续输入（不因发送失焦而被迫重点），直到用户主动收起。
- **明确不做**：麻袋聊天；新 P2P 通道；第三套聊天 UI 类；展开时放大头像本体。
- **兼容**：装配仍为 `OverlayBootstrap` / `FriendOverlayView.Build`；聊天仍走通道 1；不改 `SteamManager` / Steamworks.NET。

### 技术决策

- **单一聊天 UI**：扩展现有 `OverlayChatUi`，增加贴头像「简版」模式；侧栏「全历史」模式复用现有大面板，不新建平行聊天系统。
- **状态所有权**：当前打开的好友与模式（收起 / 简版 / 侧栏全历史）由 `OverlayChatUi`（经 `FriendOverlayView` 接线）持有；头像气泡预览文案继续由 View 刷新 Chip。
- **锚点**：简版跟随目标 Chip 的气泡锚点（头像上方）；侧栏定位可沿用现有贴头像侧边逻辑。
- **截断规则**：简版列表以「对方最近一条」为下界切片到最新；侧栏不做该截断。无对方消息时简版不伪造历史。
- **选中态**：简版或侧栏打开时，桌上该好友保持选中虚线；关闭到收起态后按现有 `RefreshChatSelection` 规则更新。

## 设计视图

### 功能设计

1. 平时桌上好友显示收起气泡（最新摘要或「…」）。
2. 用户点气泡/头像或定位 Enter → 气泡位展开为简版：截断消息列表 + 输入框；标记已读；可连续发送。
3. 用户点「全部消息」→ 打开侧栏全历史；简版会话逻辑上仍属该好友，关侧栏后回到简版。
4. 用户 Esc/关闭/再点收起 → 回到单句气泡；切换好友则简版改绑新好友。

### 技术设计

#### 整体方案

- `FriendOverlayView`：展开入口仍汇到 `OpenChat` / 定位确认；区分「打开简版」与「打开侧栏全历史」（或由 `OverlayChatUi` 内模式切换）。
- `OverlayChatUi`：`Compact`（贴气泡锚点 + 截断列表 + 简易 composer +「全部消息」按钮）与 `Full`（现有侧栏全历史）；模式切换不丢当前 `friendId`。
- `FriendAvatarChip`：收起态气泡展示；展开时可由 ChatUi 盖住/替代气泡视觉，Chip 不新开聊天业务。

#### 实现流程

入口 → 设当前好友为简版并锚到 Chip → 按截断规则 Rebuild 列表并聚焦输入 → 发送走现有 `OverlayChatService` → 「全部消息」切 Full 并 Rebuild 全量 → 关 Full 回 Compact → 收起则 Hide 并刷新选中/预览。

### 预估改动面

- 主要：`OverlayChatUi`、`FriendOverlayView`（入口/模式）、必要时 `FriendAvatarChip`（气泡与展开共存）。
- 测试：收起展示；三种展开入口；截断边界（有/无对方消息）；全部消息往返；收起与切换好友；发送后仍可连发。

## 验收

- 无消息好友 → 气泡为「…」→ 观察桌上。
- 有消息未展开 → 气泡为最新一句摘要 → 观察。
- 点气泡 / 点头像 / 定位 Enter → 头像上方出现简版（脸不变大），列表从对方最近一条到现在 → 操作观察。
- 对方从未发言时展开 → 简版可输入，不伪造对方历史 → 操作观察。
- 简版连发多条无需重点输入框 → 操作观察。
- 点发送左侧「全部消息」→ 侧栏出现全历史；关闭侧栏 → 回到简版 → 操作观察。
- Esc / 关闭 / 再点收起 → 回单句气泡；点另一好友展开 → 简版切换 → 操作观察。
- 麻袋无展开聊天 → 对照。
