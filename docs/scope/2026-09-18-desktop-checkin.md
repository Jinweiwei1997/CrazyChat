# 自己头像打卡

## 目标

自己桌上头像上方常驻一条打卡条：滑动开关 + 编辑。开关按「每日 6:00」重置；未打为红色关闭，点一下滑成绿色且当天不能取消。文案可编辑，从未编辑时默认为「嘀嘀嘀嘀，打开上班~」。悬停开关显示该文案。

## 与现有事项的对应

当前事项已经具备：设置页「事项」增删改、频率（一次 / 每日 / 每周）、完成态写入 `completedPeriod`、自己头像气泡轮播预览、点击自己头像打开「我的事项」卡片。

打卡不是平行功能，而是事项里**一条内置每日项**的桌上操作面：

| 现有事项 | 打卡如何用 |
|----------|------------|
| `TodoItem` + `overlay_prefs.json` | 打卡共用同一列表与存档，稳定 id，不新 JSON |
| `frequency = Daily` | 打卡锁定每日；设置里不可改成一次/每周，不可删除 |
| `text` / `EditTodo` | 头像旁编辑框与设置页该行输入框改的是同一文案 |
| `CompleteTodo`（只完成、不撤销） | 滑动开关只允许红→绿，对应该 API，不走可反勾的 `ToggleTodo` |
| `IsComplete` / `Period` | 每日日界从日历 0:00 改为 **当天 6:00**（所有 `Daily` 事项一起改，避免两套日历） |
| 自己头像气泡轮播 `☐/☑ + 文案` | 打卡文案改由**悬停开关**展示，不再占用轮播；其余事项仍可轮播 |
| 点击自己头像 →「我的事项」 | 保留，用来处理其它事项；打卡完成以头上开关为准 |
| 通道 1 / 2 | 事项本来就不上网；打卡同样**仅本机**，不广播给好友 |

设置里其它「一次 / 每日 / 每周」事项照旧。每周仍以周一 0:00 为周界；一次仍是永久 `once`。只有 Daily 的日界与打卡对齐到 6:00。

## 决策基线

### 需求边界

- **对象**：仅**自己**的桌上头像。好友头像、麻袋都不出现打卡条。
- **位置**：头像上方，跟随拖动，吃「放大倍数」（与名字、气泡、设置入口、互动环、按键图标同一范围）。设置/聊天/麻袋窗口仍 1:1 不缩放。
- **组成**：左侧滑动开关 + 右侧编辑按钮（Codicon 编辑样式：约 16px 图标、约 28px 点击区，默认透明、悬停浅底）。
- **数据**：启动时若没有这条内置项，则插入一条 `Daily` 事项，文案为空视为「从未编辑」，展示默认句。之后只改 `text` 与 `completedPeriod`。
- **颜色**：未打卡 = 红色关闭样式（可用 `ThemeDanger`）；已打卡 = 绿色开启样式。开启态不要用主题强调色冒充。
- **隐身**：打卡条随桌上组件一起隐藏；取消隐身后恢复。

### 明确不做

- 好友看见你的打卡、通道 2 同步、进聊天。
- 麻袋打卡。
- 当天把绿色拨回红色（头上开关与该条事项都不允许撤销）。
- 新 Manager / 新 Canvas / 新 prefs 文件 / 第二套事项列表。
- 改 `SteamManager`。

### 缺省数值

| 项 | 值 | 来源 |
|----|----|------|
| 默认文案 | 嘀嘀嘀嘀，打开上班~ | 确认 |
| 日界 | 每天 6:00（本地时区） | 确认 |
| 未打样式 | 红色关闭 | 确认 |
| 已打样式 | 绿色，再点无反应 | 确认 |
| 文案长度 | 与事项输入相同，最多 100 字、单行 | 缺省 |
| 空保存 | 视为从未编辑，回落默认文案 | 缺省 |

## 1. 编辑

1. 点击编辑按钮，在打卡条旁（或正上方）出现输入框，沿用事项输入视觉：主题输入底、1px 分隔线边框、正文约 13px、`Microsoft YaHei UI`。
2. 打开时带入当前已保存文案；若从未编辑或当前为空，输入框预填默认句「嘀嘀嘀嘀，打开上班~」，可全选改写。
3. 点确认（或 Enter）写入 `EditTodo` 的 `text`，关闭输入框。不改完成态。
4. 点空白处或 Esc：放弃本次编辑，文案不变。
5. 保存后若 trim 为空，按从未编辑处理，悬停仍显示默认句。
6. 设置 → 事项页里该内置行与头像编辑框双向同一数据；该行频率锁定「每日」、无删除。其它事项行仍可改频率、可删。

打开编辑时不要打开「我的事项」卡片，也不要关掉设置（若设置已开）。输入期间需要键盘焦点，走现有 Overlay 取焦路径。

## 2. 滑动开关

### 显示

- 常驻在自己头像上方，不占用好友聊天气泡。
- **未完成当前 6:00 日周期**：红色关闭（拨片在关侧）。
- **已完成**：绿色开启（拨片滑到开侧），当天再点无动画、不取消。
- 鼠标悬停开关（未开编辑时）：在开关旁显示玩家设定文案（从未编辑则默认句）。过长截断，不撑开头像。离开悬停后文案消失。
- 不悬停时不常驻整句文案，避免和按键图标、钓鱼气泡抢位置。

### 点击

- 红 → 绿：播放拨片滑过去，调用与 `CompleteTodo` 相同的完成逻辑，写入当前 6:00 周期。
- 已是绿：忽略点击。
- 不打开「我的事项」。点自己头像仍只负责事项列表（有其它非空事项时）。

### 每日 6 点重置

周期算法（所有 `Daily` 含打卡）：

- 以本地时间计。若当前时刻 `< 当天 6:00`，则仍属于**昨天 6:00 开始**的那一天。
- 例：9/18 06:00～9/19 05:59:59 为同一周期；9/19 06:00 起若未再点，开关回到红色关闭。
- 游戏开着跨过 6:00：立刻刷新为未打，不必重开。
- 关着游戏跨过 6:00：下次启动按当前周期判断，昨天的绿不带到新周期。

「我的事项」卡片与设置页里，同一条打卡的勾选状态必须与头上开关一致。其它 Daily 事项也按 6:00 判断是否已完成（原先按日历日 0:00 的测试边界改为 6:00）。

## 3. 和桌上其它 UI 的关系

- **设置齿轮、点击数**：仍在头像下方，不动。
- **点自己头像**：仍切换「我的事项」；无其它非空事项且只剩打卡时，列表可只显示这一条，完成只能勾不能取消。
- **自己头像原事项气泡**：展开事项卡片时仍隐藏；收起后，轮播只播**非打卡**事项。没有其它事项则不显示该气泡。
- **钓鱼**：打卡条贴头像上沿外侧；高级鱼气泡/鱼图仍在头像右上，不要盖住开关点击区。
- **按键图标**：仍从头像上方冒出；与打卡条重叠时按键图标在上层、不拦截打卡点击。
- **角色状态环（钓鱼）**：悬停自己头像出环，不要被打卡条挡住槽位；打卡条可靠上一些，或出环时打卡条让开。缺省：打卡条在头像上沿再往上留出环的半径。

## 设计视图

### 功能设计

1. 启动保证内置 Daily 打卡项存在。
2. 头像上方画开关+编辑；未完成红、已完成绿。
3. 悬停开关出设定文案；点红开关完成当日打卡。
4. 点编辑 → 输入 → 确认保存 / Esc 放弃。
5. 每帧或跨日检查 6:00 日界，到期变红。
6. 设置事项页同步文案；其它事项逻辑保持。

### 技术设计

#### 整体方案

- **数据**：`OverlayUserSettings.TodoItem` 增加稳定 id（如 `checkin`）。`Period(date)` 对 `Daily` 改为「6:00 起算的日期」。`CompleteTodo` 供开关使用；该 id 禁止 `ToggleTodo` 取消、禁止 `DeleteTodo`、禁止改频率。
- **桌上 UI**：扩现有 `OverlayTodoUi` 或 Chip 附属控件，挂 `ChromeLayer`。不要新 Bootstrap。编辑输入用 uGUI `InputField` + `Text`，视觉跟事项卡片/设置输入。
- **刷新**：沿用 `TodosChanged` 与现有「日期变化则 Refresh」。日界判断不要只比 `DateTime.Now.Date`（0:00），要按 6:00 换日。
- **自己头像气泡**：`SetTodoPreview` 轮播排除打卡 id。
- **主题**：红/绿是打卡语义色；编辑按钮、输入框仍走 `OverlaySkin`。

#### 实现流程

Load prefs → 若无打卡项则插入默认 Daily → Chip 上方绑开关状态 `IsComplete(Now)` → 点击 Complete → Save → 刷新绿。  
6:00 过后 `IsComplete` 为假 → 变红。  
编辑确认 → `EditTodo(text, Daily)`。

### 预估改动面

- `OverlayUserSettings.TodoItem.Period`（Daily 6:00）、内置打卡项、禁止删/改频/反勾。
- `OverlayTodoUi`：桌上打卡条、编辑框、预览排除打卡；设置页该行锁定。
- `FriendAvatarChip`：预留上方跟随位置，气泡不再展示打卡句。
- `OverlayTodoChecks`：Daily 边界从 0:00 改为 6:00。
- 获批后写入 `docs/game-ui-rules.md` 自己头像一节。

## 验收

- 自己头像上方有滑动开关 + 编辑；好友与麻袋没有。
- 从未编辑：悬停显示「嘀嘀嘀嘀，打开上班~」。
- 编辑确认后悬停为新文案；Esc/点外侧不保存。
- 未打为红；点击后滑到绿并写入事项完成；再点仍为绿。
- 本地 6:00 之后变回红，可再打一次。
- 设置事项页能改同一句文案；打卡行不能删、不能改频率；其它事项一次/每周行为不变。
- 点自己头像仍开「我的事项」；打卡完成态两边一致。
- 自己头像轮播气泡不再出现打卡那一句。
- 未新通道、未新 prefs 文件、未改 SteamManager。
