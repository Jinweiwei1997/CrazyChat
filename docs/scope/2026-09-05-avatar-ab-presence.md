# 桌上头像 A/B 形象与键鼠同步

## 目标

每个用户可上传闲置图 A 与活动图 B；两张齐全后，桌上头像用换图表达键鼠按下/松开，并把图片与活动状态同步给好友，替代「仅 Steam 头像 + 敲击弹跳/翻转」的输入反馈。

## 决策基线

### 需求边界

- **归属**：每人只配置自己的 A/B；好友桌上显示的是对方的图，并跟随**对方**的键鼠状态切换。
- **切换**：任一键盘或鼠标键处于按下 → 显示 B；全部松开 → **立刻**回 A。
- **启用**：A、B 都已上传才启用换图；缺一则仍用 Steam 头像，且不因键鼠换图。
- **动效**：启用 A/B 后，对该用户桌上头像关闭敲击弹性/翻转（输入反馈以换图为准）。
- **图片**：PNG/JPG；边长最长 256；单张 ≤200KB；超限自动缩小后再存。
- **同步范围**：仅当对方开着本游戏，且你的头像在对方**桌上**（不在麻袋）。麻袋条目保持纯展示，不做 A/B 玩法。
- **图片同步时机**：对方将你拖到桌上时拉取/接收一次；你在设置中改图后，向「已开游戏且桌上有你」的好友再推一次（或对端发现版本更新后自动拉新）。好友侧**无感知、无需操作**，自动换成新图。键鼠状态单独高频同步（按下/松开边沿），不在每次按键附带传图。
- **设置**：提供 A/B 上传与清除（或等同「取消启用」）能力。
- **明确不做**：新 P2P 通道；本机给好友「化妆」；改 Steam 客户端多端登录；给麻袋加 A/B 动效。
- **兼容**：装配入口仍为 `OverlayBootstrap` / `FriendOverlayView.Build`；聊天通道 1、互动/同步通道 2；不改 `SteamManager` / Steamworks.NET。

### 技术决策

- **持久化**：图片存本地文件；`OverlayUserSettings`（`overlay_prefs.json`）记录是否启用、版本/校验信息等；不新开无关 JSON 文件。
- **本机输入**：扩展或复用 `OverlayInputWatcher`，提供「当前是否存在键鼠按下」；本地 Chip 直接切 A/B。
- **联网**：一律通道 2（`IX1|`）。活动状态用短消息边沿同步；图片用通道 2 载荷传输（可分条），禁止开通道 3。
- **显示**：`FriendAvatarChip`（桌上）在启用且资源就绪时用 A/B；否则 Steam 头像。
- **设置 UI**：`OverlaySettingsUi` 增加上传/清除入口；选图走系统文件对话框（Win）。
- **职责**：不新 Bootstrap/Manager/事件总线；能进现有 Settings / Input / Chip / InteractService 的不要堆进 View。

## 设计视图

### 功能设计

1. 用户在设置中分别选择图 A、图 B；校验格式与大小，必要时缩小；存盘并更新 prefs 版本。
2. 仅当 A、B 均有效时视为「形象启用」。清除任一张后退出启用，头像回 Steam 图。
3. 本地启用时：键鼠按下 → 本机自己的桌上头像立即 B；松开 → 立即 A；并向符合条件的好友发送状态边沿。
4. 好友侧：桌上出现该用户且本机已启用形象时，确保已有其 A/B 缓存；收到活动状态后切换显示。未开游戏或未在桌上则收不到/不展示玩法。
5. 用户改图后主动推送，或对端按版本自动拉新；好友无需重装、无需点任何按钮，桌上头像自动换成新图。新拖上桌时同样自动补齐。

### 技术设计

#### 整体方案

- **设置与存储**：`OverlayUserSettings` + 本地图片文件 + `OverlaySettingsUi` 上传/清除。
- **输入**：`OverlayInputWatcher` 暴露按下集合或 `IsAnyDown`；本地订阅后更新 Local Chip，并经 `OverlayInteractService`（或同通道既有发送点）发出状态。
- **协议**：通道 2 上区分「活动状态」与「形象资源」两类 `IX1|` 消息（具体前缀实现选定）；状态仅边沿；资源带版本号避免重复狂传。
- **Chip**：桌上 Chip 根据「该 SteamId 是否启用 + 当前 active + 缓存精灵」选 A/B 或 Steam 头像；启用时跳过敲击弹跳/翻转。

#### 实现流程

设置保存 → 本地启用标志 → Input 边沿 → 本地换图 + Send 状态 → 好友 Receive → 更新该 Chip。拖上桌 / 改图 → 拉或推图片 → 缓存 → 显示。

### 预估改动面

- `OverlayUserSettings`、`OverlaySettingsUi`、`OverlayInputWatcher`、`FriendAvatarChip`、`FriendOverlayView`（接线）、`OverlayInteractService` 或同目录同步辅助。
- 可能新增少量 Overlay 下辅助类（图片读写/缩放），避免新 Manager。
- 测试：本机上传与切换；缺一张不启用；双机桌上同步状态与改图推送；麻袋无 A/B。
- wiki：不更新。

## 验收

- 只上传一张 → 仍 Steam 头像，键鼠不换图 → 设置与桌上观察。
- A、B 都上传 → 按下立刻 B、松开立刻 A（本机）→ 观察桌上自己头像。
- 启用后敲击不再弹跳/翻转 → 观察。
- 好友开着游戏且你在其桌上 → 能看到你的 A/B，并随你键鼠切换 → 双机。
- 改图后好友侧自动拉新并换图（好友无感知、无需操作/重装）→ 双机。
- 仅麻袋有你、或对方未开游戏 → 不要求同步玩法 → 双机/单机对照。
- 超大图可上传但被缩小到限制内 → 设置上传后检查文件/显示。
- 未新增通道 3；未改 SteamManager → diff。
