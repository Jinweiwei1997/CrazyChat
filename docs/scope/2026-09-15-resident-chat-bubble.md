# 桌上好友常驻聊天气泡

## 目标

桌上好友头像在无未读时也保留可点的聊天气泡占位，作为进入简易聊天的常驻入口；有未读时仍按现行轮播气泡展示。

## 决策基线

### 需求边界

- **对象**：仅桌上好友头像；麻袋不新增桌面式轮播/常驻气泡。
- **无未读**（含从未聊过、或已全部读完）：气泡常驻显示 `…`。
- **有未读**：保持现状——宽度为头像宽度的 `2/3`、半透明主题底、对方未读按旧到新每 5 秒翻页轮播；未读角标规则不变。
- **聊天打开时**（简易或完整）：隐藏该头像气泡；关闭后按是否仍有未读再显示轮播或 `…`。
- **入口**：点气泡或点头像仍打开该好友聊天；无未读时进入简易态。
- **简易消息范围**：与现行一致——有未读从最早未读对方消息起；无未读从对方最后一条起连续到最新；双方合计不超过 `OverlayConfig.maxCompactChatMessages`；对方从未发言则空列表 + 输入。
- **明确不做**：麻袋常驻气泡；改聊天通道；第二套聊天 UI；改完整历史行为。
- **兼容**：装配仍为 `OverlayBootstrap` / `FriendOverlayView.Build`；聊天通道 1；不改 `SteamManager`。

### 技术决策

- **显示所有权**：桌上气泡显隐与文案仍由 `FriendAvatarChip`（经 View 刷新预览）持有；不新建气泡系统。
- **状态规则**：`unread > 0` 用未读列表轮播；`unread == 0` 且非本地好友、聊天未展开时固定文案 `…` 并显示气泡。
- **聊天 UI**：`OverlayChatUi` 三态与截断规则不因本需求改写；仅依赖现有打开/关闭时对 Chip `SetChatExpanded` 的隐藏。
- **规则文档**：同步更新 `docs/game-ui-rules.md`（及对应 cursor 规则）中「仅有未读才显示气泡」的表述。

## 设计视图

### 功能设计

1. 桌上好友收起态始终可见气泡（聊天展开时除外）。
2. 无未读显示静态 `…`；有未读显示轮播摘要与角标。
3. 用户点气泡/头像进入聊天；关闭后若无未读回到 `…`。
4. 麻袋与本地自己头像不受本需求影响。

### 技术设计

#### 整体方案

- 扩展 `FriendAvatarChip.SetChatPreview` / `RefreshChatChrome`：无未读时将 `_bubbleContent` 设为 `…`，`showBubble` 在可聊好友且未展开时为真。
- 轮播 `Update` 逻辑仅在未读列表条数 > 1 时运行（现状已接近，保持）。
- View 继续按 Store 未读刷新预览；无需新服务。

#### 实现流程

Store/View 刷新未读预览 → Chip 根据 unread 设轮播文案或 `…` → RefreshChatChrome 显隐 → 打开聊天 SetChatExpanded(true) 隐藏 → 关闭后再次刷新显示 `…` 或轮播。

### 预估改动面

- 主要：`FriendAvatarChip.cs`；文档 `docs/game-ui-rules.md`、`.cursor/rules/game-ui-rules.mdc`。
- 测试：无未读常驻 `…`；有未读轮播；打开隐藏、关闭恢复；点 `…` 进简易。
- wiki：不更新。

## 验收

- 桌上好友无未读 → 气泡显示 `…` → 观察。
- 有未读 → 仍轮播且有角标 → 观察。
- 打开简易/完整 → 气泡隐藏；关闭后无未读回到 `…` → 操作观察。
- 点 `…` / 头像 → 进入简易；无未读时消息从对方最后一条到最新 → 操作观察。
- 麻袋无桌面常驻气泡变化 → 对照。
- 未新增通道 / 未新聊天 UI 类 → diff。
