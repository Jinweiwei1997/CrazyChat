# 桌上头像钓鱼

## 目标

玩家可把自己的桌上头像切到「钓鱼」角色状态：本机出现鱼竿和水面特效，并按间隔随机上鱼。低级鱼直接发奖；高级鱼先出可点气泡，点开后走炫舞式 QTE，成功拿高级鱼，失败或超时退化为普通鱼。鱼按鱼池配置抽出后自动转成点数。进入/上鱼/退出同步给桌上好友。

## 决策基线

### 需求边界

- **对象**：只做已经拿出来的**桌上头像**。麻袋不出现鱼竿、水面、上鱼气泡、QTE、奖励飘字。
- **归属**：钓鱼是**本机自己**的角色状态，不是对好友施放的互动。好友桌上看到的是「对方正在钓鱼」，不是自己替对方钓鱼。
- **入口与扔番茄同级**：好友互动环仍是「对好友使用」（上槽扔番茄、右槽测试）。钓鱼占用**自己头像**上同一套四槽环的上槽，文案「钓鱼」；视觉、尺寸、悬停打开/离开关闭与好友互动环一致（悬停约 `OverlayConfig.hoverOpenSeconds`，槽 36px，环随放大倍数缩放）。自己头像没有扔番茄。
- **可见前提**（与聊天/互动/A/B 相同）：对方开着本游戏，并且钓鱼者的头像在对方**桌上**（不在麻袋）。
- **通道**：聊天仍走通道 1。钓鱼状态与上鱼动效走通道 2（`IX1|`），不进聊天记录。不开通道 3。
- **无房间、无离线队列、无云端鱼获仓库**：对方没开本游戏就看不到；本机不上鱼时不补发历史鱼获。

### 明确不做

- 麻袋里钓鱼、麻袋看鱼竿。
- 把钓鱼登记成对好友施放的 `IOverlayInteractAction`（没有 from→to 飞行物）。
- 鱼类背包、手动选择是否转化；本版本配置了转化点数即自动加分。
- 新 Manager / 新 Bootstrap / 新事件总线 / 新 Canvas / 新 P2P 通道。
- 改 `SteamManager` / Steamworks.NET。

### 缺省数值

用户已给定的不改；未给定的按下表，实施时写入 `OverlayConfig`。

| 项 | 值 | 来源 |
|----|----|------|
| 咬钩间隔 | 开始钓鱼后 5～10 分钟随机一次 | 确认 |
| 高级鱼 / 低级鱼 | 20% / 80% | 确认 |
| QTE 生效区 | 滑条长度的 20%，位置随机 | 确认 |
| 高级鱼气泡倒计时 | 10 秒 | 缺省 |
| QTE 超时 | 5 秒；超时 = 失败 | 缺省 |
| 低级鱼图片渐隐 | 1.2 秒 | 缺省 |
| 奖励展示（图+点数） | 1.5 秒后消失 | 缺省 |
| 鱼竿上吊 | 约 0.6 秒 | 缺省 |
| 点数去向 | 加到自己头像下的点击数（`OverlayTapStats`） | 缺省（与扔番茄扣点击同一套数） |

## 1. 开始 / 退出钓鱼

### 入口

- 悬停**自己**的桌上头像约 0.2 秒，头像上、右、下、左出现四槽；上槽为「钓鱼」，其余空槽不可用、不触发。
- 鼠标从头像移到环上保持打开；离开头像和环后短暂延迟关闭（与好友互动环相同）。
- 点击「钓鱼」：本机进入钓鱼状态，关闭状态环。
- 已在钓鱼时，槽位显示选中（主题强调色低透明底）；再点一次「钓鱼」退出。
- 互动冷却约 0.1 秒，防止连点。
- 自己头像始终在桌上，不依赖好友是否上桌才能开始钓鱼。

### 进入后本机表现

- 自己头像旁出现**鱼竿**，头像附近出现**水面特效**。
- 鱼竿、水面跟随头像拖动，并吃「放大倍数」（与名字、气泡、设置入口、互动环、按键图标同一缩放范围）。
- 不改变头像点击、拖动、设置齿轮、待办气泡的原有热区；装饰图 `raycastTarget = false`。
- 钓鱼不关闭 A/B：有 A/B 时鱼竿/水面叠在形象上；无 A/B 时叠在 Steam 头像上。
- 聊天、设置、待办可照常开关。隐身时鱼竿/水面随桌上组件一起隐藏；取消隐身后若仍在钓鱼则恢复显示。

### 退出

再次点击「钓鱼」，或进程退出。退出后鱼竿和水面立刻消失，当前未结算的高级鱼气泡 / QTE 取消且**不发奖**。钓鱼状态不写入 prefs，重启后一定是非钓鱼。

## 2. 上鱼时机

进入钓鱼后开始计时（`Time.unscaledTime`）。每次结算完一条鱼（或取消该次时机）后，再随机 5～10 分钟等下一次。同时只存在一次未结算时机，不会叠两条鱼。

未在钓鱼时不计时。隐身时本机计时继续，只是特效被藏住。

每次咬钩先掷池：20% 走高级鱼流程，80% 走低级鱼流程。池内再按权重抽具体道具。

### 2.1 低级鱼

1. 角色**右上方**出现该道具图片（跟随头像与放大倍数）。
2. 图片渐隐消失。
3. 同步播放鱼竿上吊。
4. 按该道具转化点数发奖（见第 4 节）。

无需点击。好友只要求看到上吊，不要求看到鱼图。

### 2.2 高级鱼

1. 角色右上方出现**钓鱼气泡 + 倒计时**（跟随头像与放大倍数）。气泡可点，不挡住头像原有拖动/点击（热区只在气泡上）。
2. **倒计时结束仍未点气泡**：气泡消失，按**低级鱼**结算（抽低级池、鱼图渐隐、上吊、发低级点数）。文案上的「变成普通鱼」即走低级鱼流程。
3. **倒计时内点击气泡**：气泡立刻关掉，在头像附近打开 QTE 滑条。

#### QTE（参考 QQ 炫舞）

- 一条横向滑条；中间有一个**拨片**沿滑条来回滑动。
- 滑条上随机出现一段**生效区**，长度为滑条的 20%，整段落在滑条内。
- 玩家在拨片处于生效区内时按下鼠标，判定成功，发**高级鱼**奖励。
- 拨片在生效区外时按下，或 QTE 超时仍未按，判定失败，退化为**普通鱼**（走低级鱼结算）。
- 一次 QTE 只结算一次按下；按下后滑条关闭。
- QTE 挂可点击层（`WindowLayer`），避免桌面穿透把点击吃掉；点在 QTE 面板外不提前失败。
- QTE、倒计时气泡、生效区**仅本机**，不同步给好友。

高级鱼无论成功、失败还是倒计时变普通鱼，只要最终发了鱼，就播鱼竿上吊。

## 3. 鱼池配置

策划配置一张表即可，不进用户设置。改配置即生效，不必改代码。建议放在 `OverlayConfig`（或它引用的列表），与 `tomatoTapCost` 同类。

| 字段 | 说明 |
|------|------|
| 鱼池类型 | `低级` / `高级`。咬钩先按 80/20 选池，再在该池内抽。 |
| 道具名称 | 展示名，用于调试和以后文案；本版本奖励 UI 以图片+点数为主。 |
| 图片 | 低级鱼渐隐、获奖展示用。缺图时用占位图，不中断发奖。 |
| 转化点数 | ≥0 的整数。钓到后**自动**加到点击数，没有「保留道具」选项。 |
| 权重 | ≥0 的整数。只在**同一鱼池内部**参与加权随机。权重 0 等于抽不到。 |

规则：

- 两池独立加权。高级失败/超时变普通鱼时，重新在**低级池**加权抽取，不沿用刚才那条高级鱼再降点数。
- 某池没有任何权重大于 0 的条目：该次该池不上鱼、不发奖；若是高级失败后的低级池为空，则只播上吊、不加分。
- 点数去向是现有点击数：扔番茄扣 `tomatoTapCost`，钓鱼加配置点数，最低仍为 0。

## 4. 获得鱼之后的 UI

只要本次实际抽出了一条鱼并转化：

1. 鱼竿播放**上吊**动效（本机 + 符合条件的好友）。
2. 本机在角色右上方展示 **道具图片 + 转换后的点数**（例如图片旁 `+100`），随后消失。
3. 点击数立刻增加并刷新自己头像下方数字，本地持久化与现有点击数相同。

低级鱼的「鱼图渐隐」和「图+点数」可接在同一位置、先后播放，不要弹独立窗口。不要进聊天、不要进麻袋摘要。

## 5. 好友同步

同步对象：正在玩本游戏的 Steam 好友。接收方是否播放，只看**发送者头像此刻是否在接收方桌上**。

| 事件 | 本机 | 好友桌上有你 | 好友把你放在麻袋 / 没开游戏 |
|------|------|----------------|------------------------------|
| 进入钓鱼 | 鱼竿 + 水面 | 能看见你的鱼竿和水面 | 看不见 |
| 钓上鱼（上吊） | 上吊 + 本机奖励 UI | 只看到你的鱼竿上吊 | 看不见 |
| 退出钓鱼 | 鱼竿、水面、气泡、QTE 都关掉 | 你的鱼竿消失 | 无 |

补充：

- 好友把你从麻袋拖上桌、或对方刚开游戏时：若你仍在钓鱼，要让对方马上看到鱼竿和水面（补当前状态），不必等你再点一次。
- 你把好友收进麻袋：立刻去掉该好友头像上的鱼竿/水面；再拖回桌上时按对方当时是否在钓鱼显示。
- 只同步三种表现：进入（鱼竿+水面）、上吊、退出（鱼竿消失）。鱼图、气泡倒计时、QTE、奖励数字仅操作者本机。
- 测试好友不发 P2P；测试模式只验证本机状态与特效即可。

## 设计视图

### 功能设计

1. 悬停自己头像 → 状态环「钓鱼」→ 进入：本机鱼竿+水面，并向桌上好友发进入。
2. 5～10 分钟随机咬钩 → 20% 高级 / 80% 低级。
3. 低级：右上鱼图渐隐 → 上吊 → 本机图+点数 → 加点击数 → 广播上吊。
4. 高级：右上气泡+倒计时 → 超时当低级；点气泡开 QTE → 命中高级 / 否则低级 → 同样上吊与发奖。
5. 再点「钓鱼」→ 退出，清特效，广播退出。
6. 好友仅在桌上渲染对方的鱼竿/水面/上吊。

### 技术设计

#### 整体方案

- **状态**：钓鱼控制器挂在现有 Overlay 装配里（`FriendOverlayView.Build` 接线），持有本机 `Idle / Fishing`、下一次咬钩时刻、当前未结算时机。不新 Manager。
- **入口**：扩展现有四槽环，使自己头像也能打开**角色状态环**；「钓鱼」不要塞进 `OverlayInteractCatalog` 当对好友 `Play(from,to)`。
- **表现**：鱼竿、水面、上吊走 `OverlayInteractFx`（或 Chip 附属装饰，挂已有 `FriendLayer` / `FxLayer`）。低级鱼图、高级气泡、奖励飘字挂 `ChromeLayer`。QTE 挂 `WindowLayer`。装饰不挡穿透。
- **配置**：间隔、概率、倒计时、QTE 超时、鱼表进 `OverlayConfig`。
- **发奖**：`OverlayTapStats.Add(points)`，刷新 `LocalChip` 点击数。
- **联网**：`OverlayInteractService` 通道 2。短消息前缀与 `tap|`、`ab|` 并列，例如 `fish|e` / `fish|c` / `fish|x`（实现时可定）。对桌上好友逐个 `Send`，接收后若该 SteamId 不在桌上则忽略。
- **时间**：一律 `Time.unscaledTime`。

#### 实现流程

点钓鱼 → 本机切 Fishing、显示鱼竿水面、广播 enter、排程 5～10 分钟。  
到时掷 20/80 → 低级则抽低级池并展示/发奖/广播 catch；高级则出气泡，点开 QTE 或超时降级。  
再点钓鱼 → 取消时机、隐藏全部、广播 exit。  
好友 Receive → 只改该 Chip 的鱼竿/水面/上吊。拖上桌时询问或使用已缓存的对方钓鱼标志。

### 预估改动面

- 主要：自己头像状态环（扩展 `OverlayInteractUi` 或紧邻辅助）、钓鱼状态/计时/抽奖、Fx（鱼竿/水面/上吊/鱼图/气泡/QTE）、通道 2 短协议、`OverlayConfig` 鱼表、`FriendOverlayView` 接线、`FriendAvatarChip` 跟随点。
- 文档：获批实施后把入口、缩放范围、同步前提写进 `docs/game-ui-rules.md`。
- wiki：不更新。

## 验收

- 悬停自己头像出现与好友环同级的四槽，上槽「钓鱼」；点一次出鱼竿和水面，再点一次消失。
- 好友环仍是扔番茄/测试，点扔番茄行为不变。
- 钓鱼后 5～10 分钟内出现一次咬钩；连续两次咬钩之间仍是 5～10 分钟。
- 低级鱼：右上鱼图渐隐，加对应点数，鱼竿上吊。
- 高级鱼：右上气泡+倒计时；不点等到结束 → 按低级鱼发奖；倒计时内点开 QTE。
- QTE：拨片来回，生效区约 20% 且位置会变；区内点击得高级鱼点数；区外点击或超时得低级鱼点数。
- 获奖时本机看到道具图 + 点数，头像下点击数增加。
- A 钓鱼且 A 在 B 桌上：B 看见鱼竿和水面；A 上鱼时 B 看见上吊；A 退出后 B 侧鱼竿消失。
- A 在 B 的麻袋里：B 看不见鱼竿/水面/上吊；B 把 A 拖上桌时，若 A 仍在钓鱼则立即看到。
- 麻袋条目无钓鱼 UI。隐身时鱼竿水面隐藏，取消隐身且仍在钓鱼则恢复。
- 未新开通道 3、未新 Manager、未改 SteamManager。
