# CrazyChat 界面需求备忘（现行）

> 新 AI 窗口先读本文，再读 [ai-code-guide.md](ai-code-guide.md)。
>
> 本文记录现行界面、按钮和交互规则，是界面需求基线。
>
> `桌面互动伙伴需求.md` 是早期草案，不是现行需求。

## 0. 全局规则

- 好友关系和在线状态来自 Steam。
- 玩法只作用于已经拿出来的**桌上头像**。
- 对方看见聊天、互动、A/B 形象、按键反应和钓鱼表现的前提：对方开着本游戏，并且**你的头像在对方桌上**（不在麻袋）。可见性只看接收方桌上是否有你，不要求你也把他放在桌上。
- 麻袋按现有代码显示头像、名字、最后一条消息摘要和未读角标；点击条目可打开聊天。A/B、按键反应、互动和钓鱼仍只作用于桌上头像。
- 设置与聊天窗口使用 1:1 像素尺寸。桌上头像、设置入口、互动环和麻袋使用各自固定尺寸。
- 聊天走通道 1；互动、点击同步、A/B 同步和钓鱼状态同步走通道 2。
- 聊天实时发送并保存在本机；好友形象由好友本人设置。
- 设置与聊天窗口统一采用 VS Code 式扁平视觉：方角/极小圆角、1px 分隔线、紧凑间距；Codicons 以透明 PNG Sprite 使用并随深浅主题染色。工具按钮图标约 16px、点击区约 28px，默认透明，悬停才显示浅色背景。
- Windows 正文使用 `Microsoft YaHei UI`，字体缺失时使用项目内置 `Noto Sans SC`；设置与聊天卡片按 1:1 像素渲染。

常用数值从 `OverlayConfig` 读取：头像 128；桌上好友最多 30；总收集最多 64；未读显示封顶 99+；悬停打开约 0.2 秒；互动冷却 0.1 秒；未读气泡轮播 5 秒；右键隐藏 2 秒；双击 Ctrl 间隔 0.4 秒；番茄扣点击数读取 `tomatoTapCost`。

## 1. 桌面主界面

### 显示

- 透明桌面叠层，默认始终置顶；无可交互 UI 的地方应保持点击穿透。
- 默认展示自己和正在玩本游戏的在线 Steam 好友。
- 好友列表在启动时刷新一次，之后由 Steam 上下线、游戏状态、名字和头像事件驱动刷新。从麻袋拖回桌面时主动刷新一次好友数据。
- 桌上头像不显示常驻纯色底图或纯色边框。
- 好友离线或退出本游戏后，其头像从当前界面消失。
- 头像位置持久化；分辨率变化时自动限制在屏幕范围内。
- 左下状态文字显示 Steam 未连接、在线/正在玩人数和麻袋人数。
- Windows 打包版启动后在系统通知区显示 `CrazyChat` 托盘图标，显示位置由 Windows 管理。
- 托盘右键提供「退出」和隐身时的「取消隐藏」。
- **隐身**：游戏运行中全局按住鼠标右键 2 秒，桌上组件渐隐并隐藏；鼠标旁显示原尺寸 1/4 的环形进度与文案「隐藏」。提前松开右键时恢复显示；进入隐身时关闭聊天和设置浮层。
- **取消隐身**：再按住右键 2 秒（进度文案「取消隐藏」并渐显），或 Standalone 托盘右键「取消隐藏」立刻恢复。隐身状态不跨重启。Editor Play 支持长按隐身（无托盘项时只能长按取消）。

### 窗口焦点与穿透

硬约束，详见 `.cursor/rules/overlay-window-focus.mdc`：

- 禁止 `AttachThreadInput`、Join 他进程输入队列、hardSteal/forceSteal，以及在 `Update`/悬停循环里高频 `SetForegroundWindow`。
- 仅允许软抢前台：打开聊天（或其它需键盘面板）、鼠标悬停进入可交互 UI（限频 ≥0.75s）。
- 聊天打开期间 `SetUiCaptureLatch(true)`，关闭时清除；软抢失败仍可靠 latch 点击输入，不得再加 `AttachThreadInput`。
- 前台切到其它应用（曾获键盘前台后失焦，或开聊 settle 后 `OnApplicationFocus(false)`）→ 自动 `Hide` 聊天，不要只 `ReleaseInputFocus`。

### 操作

- 拖动头像：移动并保存位置。
- “放大倍数”只缩放桌上头像及其附属名字、未读气泡、设置入口、互动环、按键图标、钓鱼鱼竿/水面/气泡/QTE；设置窗口、聊天窗口、麻袋及其他界面保持固定尺寸。
- 将好友头像拖到麻袋：收进麻袋并从桌上移除。
- 自己头像固定显示在桌面。
- `DisableDrag` 开启时锁定桌上头像和麻袋条目的位置。

## 2. 自己头像界面

### 显示

- 显示自己的 Steam 头像；启用 A/B 动态形象后改显示自己的 A/B 图。
- 头像下方显示永久累计的键鼠点击数。
- Codicons 齿轮设置按钮与头像下方点击数对齐，放在数字右侧且保持在头像图片宽度内；齿轮图标为普通工具图标的 1.5 倍（24px），点击区不变。数字始终居中，位数过多时自动缩小字号。
- 头像上方打卡滑动条（仅本机，受设置「显示打卡」控制）：整条宽度不超过头像宽；必须拖到右侧才完成，到位后拨片变绿对勾并有滑动特效；测试模式完成不落库。悬停开关时在鼠标旁用普通方形字提示文案。自己头像不显示事项预览气泡。细则见 `docs/scope/2026-09-18-desktop-checkin.md`。
- 聊天气泡、未读角标和互动环显示在好友头像上。

### 键鼠反应

- Windows 下即使焦点在其他程序，键盘键或鼠标键的新按下也计数一次。
- 未启用 A/B 时，按键触发头像点击反应；反应经通道 2 发给正在玩的好友，对方仅在桌上有你时播放。
- 启用 A/B 后：任一键鼠按下显示 B，全部松开立即显示 A。
- 开启“按键图标”后，按键图标以原尺寸的 1.5 倍（基础 48px）从自己头像上方冒出；未启用 A/B 时可随点击反应同步。
- 点击数本地持久化；扔番茄会扣 1000，最低为 0。

## 3. 桌上好友头像界面

### 收起状态

- 组成：头像、头像内底部的悬停/选中名字、单句气泡和未读红点。
- 单句气泡紧贴头像并常驻（聊天展开时除外）；宽度固定为头像宽度的 `2/3`，使用半透明主题底色。
- 无未读时气泡显示 `…`；有未读时按旧到新每 5 秒轮播对方未读摘要，通过旧文字向上离开、新文字从下方进入的翻页动画切换；气泡文字使用 16px，过长截断。
- 未读数量使用类似微信的固定红色圆形角标和白色数字显示，数字封顶 99+；无未读不显示角标。
- 轮播切换时有轻微淡入。
- 悬停头像时在头像内部底边显示名字，使用粗体白字和深色描边，自动缩小时最低 12px。

### 头像/气泡操作

- 左键点好友头像或气泡：打开该好友的聊天界面。
- 已打开该好友聊天时再次点击：收起聊天。
- 点击另一好友：聊天直接切换到另一好友。
- 打开聊天后清除该好友未读；展开聊天时隐藏原单句气泡，头像大小不变。
- 关闭聊天后：若仍有未读则恢复轮播气泡，否则显示常驻 `…`。
- 拖动头像：移动位置；拖到麻袋则收起。
- 悬停头像约 0.2 秒：显示互动环。

### A/B 形象

- 默认显示好友 Steam 头像。
- 好友自己设置 A、B 两张图且资源完整后，桌上显示其 A/B 形象。
- A/B 图保留 PNG 透明区域，并按正方形头像区域裁出圆角；透明区域下不显示纯色底图。
- 视觉透明和圆角不改变原有方形点击、拖动、悬浮及选中区域。
- 显示跟随**对方**键鼠状态：按下为 B，松开为 A。
- 好友改图后，桌上使用者自动收到更新，无需按钮或确认。
- A/B 形象显示在桌上头像。

## 4. 键盘选择好友

仅在聊天输入框未聚焦时生效：

- 双击 `Ctrl`：进入好友选择，目标头像持续显示名字。
- `←` / `→`：循环切换桌上好友。
- 初始顺序优先最近有消息的好友；无消息时按稳定顺序。
- `Enter`：打开当前目标的聊天界面。
- `Esc`：取消选择。
- 只选择桌上好友，不选择自己或麻袋条目。

## 5. 聊天界面

### 显示规则

- 聊天分为互斥的收起气泡、简易聊天窗口、完整历史窗口三态。
- 设置窗口、简易聊天和完整历史聊天的宽度按此前宽度的 0.7 倍显示，高度不变。
- 简易和完整窗口优先贴在目标头像上方；顶部空间不足时翻到头像下方，四边始终限制在当前屏幕内。任一窗口打开时隐藏头像气泡。
- 简易窗口高度按当前实际显示的消息内容收缩，最多增长到原简易窗口高度；完整历史窗口保持固定高度。
- 头像本体不放大。
- 简易窗口的消息范围从最早一条未读对方消息开始；无未读时，从对方最后一条消息开始，连续显示到当前最后一条。
- 对方尚无消息时消息区初始留空；打开后本次会话新收发的消息继续追加。
- 简易窗口最多显示 `OverlayConfig.maxCompactChatMessages` 条，默认 10 条，双方消息合计；超过上限时显示最近消息。
- 打开界面即标记该好友消息已读。
- 消息时间以居中弱化小字显示在气泡上方：首条以及与上一条间隔超过 5 分钟时才出现；当天显示 `HH:mm`，昨天显示 `昨天 HH:mm`，今年显示 `M月d日 HH:mm`，更早显示 `yyyy年M月d日 HH:mm`。简易和完整历史窗口一致。
- 完整历史窗口显示本地保存的全部消息，并允许继续聊天。

### 控件

- `输入框`：无论通过头像点击还是键盘选择打开聊天，仅用软抢前台（`SetForegroundWindow` + `SetFocus`，禁止 `AttachThreadInput`）并自动聚焦输入框；软抢失败时仍可靠 `SetUiCaptureLatch` 点选输入。界面打开期间保持可输入状态。
- `发送图标`：发送当前非空消息；发送后清空输入框并继续聚焦，允许连续发送。
- `历史/返回图标`：简易窗口中点击进入完整历史；完整历史中该按钮位于发送按钮右侧，点击返回简易窗口。
- `Enter`：发送消息并继续聚焦输入框。
- `关闭`：关闭聊天界面，回到头像常驻气泡（无未读为 `…`，有未读为轮播）。
- `Esc`：收起到头像常驻气泡。

### 切换规则

- 点同一好友头像/气泡：收起。
- 点另一好友头像/气泡：聊天界面直接切换目标。
- 目标好友从在线列表消失：自动关闭聊天。
- 前台切到其它应用（曾获键盘前台后失焦，或开聊 settle 后 `OnApplicationFocus(false)`）：自动关闭聊天，不要只释放输入焦点却留着窗。
- 桌上头像和麻袋条目都可打开聊天；键盘选择仍只选择桌上好友。
- 静态聊天窗口统一使用 `Resources/Prefab/UI/ChatPanel.prefab`；消息行按数据动态生成，不保留运行时静态 UI fallback。
- 聊天标题栏约 32px、正文约 13px；关闭/发送/历史按钮均使用透明工具按钮样式，输入框保留 1px 主题边框，卡片不使用阴影。

## 6. 聊天存储与联网规则

- 使用通道 1（`CC1|`）。
- 发送时本机会立即记入历史；对方没开本游戏则收不到。
- 聊天记录保存在本机；每位好友默认最多 200 条，消息在双方同时运行游戏时实时送达。

## 7. 好友互动环与自己状态环

### 打开/关闭

- 悬停桌上好友约 0.2 秒后，在头像上、右、下、左显示 4 个槽位（好友互动环）。
- 悬停自己桌上头像约 0.2 秒后，同样显示四槽（自己状态环）；视觉、尺寸与好友环一致。
- 鼠标从头像移到环时保持打开。
- 鼠标离开头像和环后短暂延迟关闭。
- 空槽不可用，不应触发任何效果。

### 好友环当前按钮

- `扔番茄`：从自己头像向目标好友播放番茄特效；通过通道 2 发给目标；本机扣除 `OverlayConfig.tomatoTapCost`。
- 右侧 `测试`：在本机模拟目标好友发来一条随机数字消息，用于检查未读气泡和聊天界面。
- 左侧 `放烟花`：在目标头像播放程序化粒子烟花；通过通道 2 发给目标。
- 互动有约 0.1 秒冷却，防止重复触发。

### 自己状态环

- 上槽 `钓鱼`：切换本机钓鱼角色状态（不是对好友施放的互动，不进 `OverlayInteractCatalog`）。
- 已在钓鱼时槽位显示选中（主题强调色更高透明底）；再点一次退出。
- 测试模式下右槽 `QTE`：调用 `SimulateFishingQte`，跳过气泡直接弹出高级鱼 QTE（未钓鱼时先进入）；正式模式不显示。
- 其余空槽不可用；自己头像没有扔番茄。

### 钓鱼（桌上自己）

- 进入后本机显示鱼竿和水面（跟随头像与放大倍数）；鱼竿和水面渲染在头像图层之后（`UnderFriendLayer`），气泡、QTE 和收获提示仍在头像之上；隐身时随桌上组件隐藏。
- 正式模式约 5～10 分钟随机咬钩；测试模式约 8～20 秒。20% 高级 / 80% 低级，再按 `OverlayConfig.fishingFish` 权重抽具体鱼。
- 低级：右上鱼图渐隐 → 上吊 → 图+点数 → 点数加到点击数（`OverlayTapStats`）。
- 高级：右上气泡+倒计时；超时按低级结算；点开后本机 QTE（拨片+20% 生效区）；命中得高级鱼，否则低级。气泡/QTE/奖励数字仅本机。
- 通道 2 短协议：`fish|e` 进入 / `fish|x` 退出 / `fish|c` 上吊（发生时广播给正在玩的好友）；`fish|q` 查询，对方用 `e` 或 `x` 回应当前状态。接收方仅当发送者头像在自己桌上时显示鱼竿/水面/上吊（麻袋看不见）。上桌或游戏启动/好友新出现在在玩列表时发一次查询，同一好友本局不重复问。
- 钓鱼状态不写 prefs；退出或进程结束清特效，未结算气泡/QTE 不发奖。

### 边界

- 好友互动环只属于桌上好友，不出现在麻袋。
- 自己状态环只属于自己桌上头像，不出现在麻袋。
- 接收方只有在桌上放着发送者头像时才播放收到的互动、按键反应、A/B 或钓鱼表现；与发送方是否把接收方放在桌上无关。
- 点击反应不是互动按钮，不登记进互动目录。
- 对好友施放的新互动必须复用 `IOverlayInteractAction`、Catalog、Fx 和通道 2。
- 钓鱼是本机角色状态，不要登记成对好友的 `Play(from,to)`。

## 8. 麻袋界面

### 显示

- 位于右下角；存在桌上好友或袋内好友时显示入口。
- 收起时按钮显示“麻袋”及数量；展开时显示袋内列表。
- 袋内条目显示 Steam 头像、名字和最后一条消息摘要。
- 袋内条目显示各自的未读角标；麻袋入口显示袋内未读总数。
- 桌面轮播气泡、A/B、按键反应、互动按钮和钓鱼属于桌上头像。

### 控件

- `麻袋 / 收起`：展开或折叠列表。
- 拖桌上好友到麻袋：收进袋内。
- 从袋内向桌面拖出：放到松手位置并保存。
- 桌上已满 30 人时拖出好友：必须先腾出一个桌上名额；现有分配逻辑负责收起一个好友。
- 点击袋内条目打开该好友聊天；拖动仍用于把好友拿回桌面。

### 修改限制

- 麻袋已有聊天摘要、未读和聊天入口可以继续维护；其他新玩法默认只接桌上头像。
- A/B、按键反应、互动、钓鱼和桌面轮播气泡保持桌上头像范围。

## 9. 设置入口与设置面板

### 实现基线

- 设置界面运行时实例化 `Resources/Prefab/UI/SettingsMenu.prefab`。
- Prefab 的初始结构与 `OverlaySettingsUi.Build()` 生成结果一致；四个页签、四页内容和颜色编辑器、A/B 图槽都预先做在 Prefab 里。`Build()` / `EditorPopulate()` 只用于编辑器生成和结构对照。
- 运行时 `Create()` / `Bind()` 只查找已有节点并接线，不再补页签、补页面或补控件。
- 设置面板以背景色和强调色两种主色派生完整视觉：风格 1 使用深色背景与粉色强调，风格 2 使用浅色背景与灰色强调；文字按背景明暗自动使用黑色或白色。两套共用方角面板和低圆角控件，并同步应用到头像聊天气泡、简易聊天和完整历史窗口。
- 显示页提供风格行和 RGB 滑条：点击背景颜色或强调颜色行后编辑对应颜色，确认后进入自定义主题；再次点击风格行恢复深浅预设。
- 标题左对齐并留出边距；游戏/显示/动态/系统页签使用文字，右上角关闭按钮和设置入口使用对应 Codicons，关闭按钮无底色。按钮只保留约 1–2 像素的视觉圆角，开关文字高度约占按钮的一半。
- 标题约 14px、正文约 13px；页签、操作行及关闭按钮默认透明，悬停显示主题浅底，选中页签和开启状态使用低透明度强调色。
- 设置面板主体保持固定紧凑高度并使用 1:1 像素渲染；四个页签切换时窗口尺寸不变化。设置入口大小不变。
- 其他界面暂不因本次迁移而改造，后续逐个确认、逐个切换到 Prefab。

### 入口

- Codicons 齿轮设置按钮跟随自己头像，和头像下方点击数对齐并放在数字右侧，保持在头像图片宽度内。
- 点击设置按钮切换设置面板的打开和关闭。
- 设置、聊天打开后，点击界面外空白区域关闭；点击界面内部不关闭。互动环继续按悬停规则打开和离开关闭。
- 打开设置时关闭好友互动环。
- `关闭`：关闭设置；若动态页正在裁剪，一并放弃本次裁剪。

### “游戏”页

- `−`：整体头像缩放减少 0.1。
- `+`：整体头像缩放增加 0.1。
- 缩放范围 0.5–2.5；默认 1.0。
- `烟花大小`：左侧放烟花特效相对当前默认尺寸的倍数；`−` / `+` 每次 0.1，范围 0.5–2.5，默认 1.0。设置状态持久化。
- `测试模式`：开启后在桌面默认加入 3 个模拟为在线且已打开本游戏的测试好友；关闭后移除这些测试好友。设置状态持久化。测试模式下打卡滑动完成**不写入**完成态，可重复试。
- `显示打卡`：控制自己头像上方打卡滑动条是否显示；关闭后隐藏 UI，不清除打卡文案/完成数据。默认开。
- `DisableDrag` 保留已有持久化值。
- `水平翻转`：只改变自己的头像朝向。
- `按键图标`：控制是否显示/同步按键图标。
- `复位头像位置`：恢复当前桌上头像默认排列并保存。
- `复位缩放`：恢复 1.0。

设置页签为游戏/显示/动态/系统；**不再提供「事项」页签**。

### “显示”页

- `界面风格 1 / 2`：点击在两套设置主题之间切换。
- `背景颜色 / 强调颜色`：选中后用本页 RGB 滑条编辑，确认后启用自定义主题。

### “动态”页

- 两个图槽：`闲置图 A`、`动态图 B`。两张图都有效才启用。
- `清除`：删除 A/B 两张图，头像回 Steam 图。
- 收藏格：三格排成一排，缩略图可压出格子边界，图片垫方形白底。√（`codicon_check_bold`）在缩略图左上角、红叉（`codicon_close_bold`）在右上角，都是 15px 圆底加 11px 图标；圆底分别用 `ThemeSuccess` 绿和 `ThemeDanger` 红，图标按底色取对比色。保存（`codicon_save` 染正文色、无底，30px 点击区加 22px 图标）单独放在格子下方。红叉只在有图时出现，√ 只在这一格有完整图时出现；保存把当前 A/B 图和缩放写入这一格，当前 A/B 不完整时不可点。三个图标统一按 64px 画布里 48px 内容框烘制；角标只有 11px，codicon 原笔画在这个尺寸下是发丝线，所以 √/× 用加粗版（笔画约 2.9/16），标题栏关闭键仍用常规 `codicon_close`。
- 小尺寸图标防锯齿：图标 PNG 要开 mipmap（`enableMipMap: 1` + `mipMapsPreserveCoverage: 1`），程序化圆底 `OverlaySprites.Circle` 也带 mip 链。64px 或 128px 贴图缩到 11~22px 时没有 mip 链就会欠采样出锯齿。
- A/B 图上的说明条底 `TipBg` 用半透明 `ThemeBackground`、文字取对比色；裁剪台底板 `Frame` 用 `ThemeInputBackground`；空槽位 `+` 用 `ThemeMuted`。整页不留硬编码黑白底。
- 选图后本页切换到裁剪视图：拖动、滚轮或按住缩小/放大，取消回图槽，确认写入对应 A/B 槽。

### “系统”页

- `始终置顶`：控制透明窗口置顶，默认开。
- `开机自启`：控制 Windows 登录后自动启动。
- `显示器`：下拉选项按当前连接数量显示 `1 / 2 / 3...`，选择后把透明桌面窗口切换到对应屏幕；选择写入现有用户设置。
- `退出游戏`：退出 CrazyChat。

用户设置统一保存在 `OverlayUserSettings` / `overlay_prefs.json`。

## 10. A/B 动态形象

### 图片规则

- 接受系统能读取的 PNG/JPG 图片。
- 保存前统一转 PNG；最长边不超过 256；单张不超过 200KB，超出时自动缩小。
- 图片和版本变化后经通道 2 同步给正在玩本游戏的好友；对方仅在桌上有你时应用。

## 11. 方形裁剪（动态页内）

裁剪做在设置「动态」页里，不单独弹窗。选图后隐藏图槽，显示裁剪视图；取消或确认后回到图槽。

### 操作

- 拖动画面：移动裁剪位置。
- 鼠标滚轮：缩放图片。
- `缩小` / `放大`：缩放图片；按住可持续缩放。缩小下限为图片铺满方形裁剪框（不露黑边），放大上限约 4 倍。
- `取消`：放弃本次选择，回到动态页图槽。
- `确认`：输出方形裁剪图，保存到刚才选择的 A 或 B 图槽。

## 12. 会话提示界面

- 本机已运行一份 CrazyChat，再启动时显示“CrazyChat 已在本机运行”，随后退出后开的实例。
- 同一 Steam 账号在另一设备后开游戏时，先开的实例显示“已在其他设备登录 CrazyChat”，约 2.5 秒后退出。
- 只在别处登录 Steam、但没开本游戏，不触发退出。
- Steam 云不可用时，跨设备顶号可降级失效；本机单实例仍保留。

## 13. AI 修改前检查

- 需求是否属于麻袋现有的摘要、未读或聊天入口？除此之外的新玩法默认只做桌上头像。
- 新控件放入职责对应的现有 `*Ui`。
- 按钮点击后的打开、返回、关闭状态是否符合本文？
- 聊天是否仍走通道 1？互动/A/B/点击同步是否仍走通道 2？
- 是否误加了离线、云端、房间、匹配或麻袋的新玩法？
- 是否把设置写进现有用户设置，把策划数值写进 `OverlayConfig`？
