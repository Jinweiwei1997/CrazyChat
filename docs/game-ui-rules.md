# CrazyChat 界面需求备忘（现行）

> 新 AI 窗口先读本文，再读 [ai-code-guide.md](ai-code-guide.md)。
>
> 本文记录应保留的界面、按钮和交互规则，是界面需求基线。代码与本文冲突时，不要自行扩大功能；先按本文理解，必要时向用户确认。
>
> `桌面互动伙伴需求.md` 是早期草案，不是现行需求。

## 0. 全局规则

- 没有房间、匹配或大厅。好友来自 Steam。
- 玩法只作用于已经拿出来的**桌上头像**。
- 对方看见聊天、互动、A/B 形象和按键反应的前提：对方开着本游戏，并且你的头像在对方桌上。
- 麻袋默认仅展示头像和名字；除非用户明确要求改麻袋，否则不要给它增加聊天、未读、气泡、A/B、动画或互动。
- 设置与聊天窗口使用 1:1 像素尺寸；动态形象设置和裁剪窗口按原尺寸的 1.3 倍显示。不影响桌上头像、设置入口、互动环或麻袋。
- 聊天走通道 1；互动、点击同步和 A/B 同步走通道 2；不要新增通道。
- 不做离线消息队列、云端聊天、本机替好友设置形象。
- 设置与聊天窗口统一采用 VS Code 式扁平视觉：方角/极小圆角、1px 分隔线、紧凑间距；Codicons 以透明 PNG Sprite 使用并随深浅主题染色。工具按钮图标约 16px、点击区约 28px，默认透明，悬停才显示浅色背景。
- Windows 正文优先使用针对小字号优化的 `Microsoft YaHei UI`，项目内置 `Noto Sans SC` 仅作字体缺失时的后备；设置与聊天卡片按 1:1 像素渲染，不再使用非整数整体缩放，以避免 uGUI 文字发虚。

常用数值从 `OverlayConfig` 读取：头像 128；桌上好友最多 30；总收集最多 64；未读显示封顶 99+；悬停打开约 0.2 秒；互动冷却 0.1 秒；番茄扣 1000 点击。

## 1. 桌面主界面

### 显示

- 透明桌面叠层，默认始终置顶；无可交互 UI 的地方应保持点击穿透。
- 默认展示自己和正在玩本游戏的在线 Steam 好友。
- 自己头像为金色圈；好友头像为绿色圈。
- 好友离线或退出本游戏后，其头像从当前界面消失。
- 头像位置持久化；分辨率变化时不能跑出屏幕。
- 左下状态文字显示 Steam 未连接、在线/正在玩人数和麻袋人数。
- Windows 打包版（Standalone exe）启动成功后，在系统通知区显示托盘小图标；悬停提示为 `CrazyChat`。是否出现在任务栏旁或「显示隐藏的图标」溢出区由 Windows / 用户决定，应用不强制搬迁。
- 托盘左键无操作；右键仅「退出」，效果与设置页「退出游戏」相同。Unity Editor Play 不显示托盘。托盘创建失败不阻断游戏启动。
- **隐身**：游戏运行中全局按住鼠标右键 2 秒，桌上组件（麻袋、自己/好友头像及附属 UI、左下状态、设置入口、互动环等）渐隐并隐藏；鼠标旁显示原尺寸 1/4 的环形进度与文案「隐藏」，文案字号不随转盘缩小。未满 2 秒松开则立刻恢复显示并关闭进度环。进入隐身时关闭聊天/设置等浮层，恢复后不自动重开。
- **取消隐身**：再按住右键 2 秒（进度文案「取消隐藏」并渐显），或 Standalone 托盘右键「取消隐藏」立刻恢复。隐身状态不跨重启。Editor Play 支持长按隐身（无托盘项时只能长按取消）。

### 操作

- 拖动头像：移动并保存位置。
- “放大倍数”只缩放桌上头像及其附属名字、未读气泡、设置入口、互动环和按键图标；设置窗口、聊天窗口、麻袋及其他界面保持固定尺寸。
- 将好友头像拖到麻袋：收进麻袋并从桌上移除。
- 自己头像不能放进麻袋。
- 开启“禁止拖动”后，桌上头像和麻袋条目都不能拖。

## 2. 自己头像界面

### 显示

- 显示自己的 Steam 头像；启用 A/B 动态形象后改显示自己的 A/B 图。
- 头像下方显示永久累计的键鼠点击数。
- Codicons 齿轮设置按钮与头像下方点击数对齐，放在数字右侧且保持在头像图片宽度内；齿轮图标为普通工具图标的 1.5 倍（24px），点击区不变。数字始终居中，位数过多时自动缩小字号。
- 自己没有聊天气泡、未读红点或互动环。

### 键鼠反应

- Windows 下即使焦点在其他程序，键盘键或鼠标键的新按下也计数一次。
- 未启用 A/B 时，按键触发头像点击反应；反应可同步给桌上好友。
- 启用 A/B 后：任一键鼠按下显示 B，全部松开立即显示 A，不再播放弹跳/翻转。
- 开启“按键图标”后，按键图标以原尺寸的 1.5 倍（基础 48px）从自己头像上方冒出；未启用 A/B 时可随点击反应同步。
- 点击数本地持久化；扔番茄会扣 1000，最低为 0。
- 每 1000 次彩蛋目前只有配置，没有具体界面或效果；不要假设已经实现。

## 3. 桌上好友头像界面

### 收起状态

- 组成：头像、头像内底部的悬停名字、单句气泡、未读红点、选中强调边框。
- 单句气泡紧贴头像，只在有未读时显示；宽度固定为头像宽度的 `2/3`，不随文字长度变化，使用不抢眼的半透明主题底色。
- 多条未读按旧到新每 5 秒轮播，通过旧文字向上离开、新文字从下方进入的翻页动画切换；气泡文字使用 16px，过长截断。
- 未读数量使用类似微信的固定红色圆形角标和白色数字显示，数字封顶 99+，不随主题改色。
- 轮播切换时有轻微淡入。
- 只有悬停头像时显示名字；名字限制在头像内部底边，不显示背景色块，使用较大的粗体白字和深色描边保证可读性，自动缩小时不低于 12px。

### 头像/气泡操作

- 左键点好友头像或气泡：打开该好友的聊天界面。
- 已打开该好友聊天时再次点击：收起聊天。
- 点击另一好友：聊天直接切换到另一好友。
- 打开聊天后清除该好友未读并隐藏气泡。
- 展开聊天时隐藏原单句气泡，但头像大小不变。
- 拖动头像：移动位置；拖到麻袋则收起。
- 悬停头像约 0.2 秒：显示互动环。

### A/B 形象

- 默认显示好友 Steam 头像。
- 好友自己设置 A、B 两张图且资源完整后，桌上显示其 A/B 形象。
- 显示跟随**对方**键鼠状态：按下为 B，松开为 A。
- 好友改图后，桌上使用者自动收到更新，无需按钮或确认。
- A/B 只显示在桌上，不显示在麻袋。

## 4. 键盘选择好友

仅在聊天输入框未聚焦时生效：

- 双击 `Ctrl`：进入好友选择，给目标头像显示主题强调色边框。
- `←` / `→`：循环切换桌上好友。
- 初始顺序优先最近有消息的好友；无消息时按稳定顺序。
- `Enter`：打开当前目标的聊天界面。
- `Esc`：取消选择。
- 只选择桌上好友，不选择自己或麻袋条目。

## 5. 聊天界面

### 显示规则

- 聊天分为互斥的收起气泡、简易聊天窗口、完整历史窗口三态。
- 设置窗口、简易聊天和完整历史聊天的宽度按此前宽度的 0.7 倍显示，高度不变。
- 简易和完整窗口优先贴在目标头像上方；顶部空间不足时翻到头像下方，四边始终限制在当前屏幕内。任一窗口打开时隐藏头像气泡。
- 简易窗口高度按当前实际显示的消息内容收缩，最多增长到原简易窗口高度；完整历史窗口保持固定高度。
- 头像本体不放大。
- 简易窗口的消息范围从最早一条未读对方消息开始；没有未读时，从对方最后一条消息开始，一直连续显示到当前最后一条，不区分发送方。
- 对方从未发过消息时消息区初始留空；打开后本次会话新收发的消息继续追加。
- 简易窗口最多显示 `OverlayConfig.maxCompactChatMessages` 条，默认 5 条，双方消息合计。超过上限只保留范围内最近的消息，较早的未读或对方消息可以被后来发送的消息挤走，不强制保留上下文。
- 打开界面即标记该好友消息已读。
- 完整历史窗口显示本地保存的全部消息，并允许继续聊天。

### 控件

- `输入框`：无论通过头像点击还是键盘选择打开聊天，游戏窗口都会取得键盘焦点并自动聚焦输入框；界面打开期间保持可输入状态。
- `发送图标`：发送当前非空消息；发送后清空输入框并继续聚焦，允许连续发送。
- `历史/返回图标`：简易窗口中点击进入完整历史；完整历史中该按钮位于发送按钮右侧，点击返回简易窗口。
- `Enter`：发送消息并继续聚焦输入框。
- `关闭`：关闭聊天界面，回到头像单句气泡。
- `Esc`：收起到头像单句气泡。

### 切换规则

- 点同一好友头像/气泡：收起。
- 点另一好友头像/气泡：聊天界面直接切换目标。
- 目标好友从在线列表消失：自动关闭聊天。
- 只给桌上头像提供聊天入口；不要给麻袋增加聊天入口。
- 静态聊天窗口统一使用 `Resources/Prefab/UI/ChatPanel.prefab`；消息行按数据动态生成，不保留运行时静态 UI fallback。
- 聊天标题栏约 32px、正文约 13px；关闭/发送/历史按钮均使用透明工具按钮样式，输入框保留 1px 主题边框，卡片不使用阴影。

## 6. 聊天存储与联网规则

- 使用通道 1（`CC1|`）。
- 发送时本机会立即记入历史；对方没开本游戏则收不到。
- 聊天记录仅本地保存；每位好友默认最多 200 条。
- 不补发离线消息，不做云同步。

## 7. 好友互动环

### 打开/关闭

- 悬停桌上好友约 0.2 秒后，在头像上、右、下、左显示 4 个槽位。
- 鼠标从头像移到互动环时保持打开。
- 鼠标离开头像和互动环后短暂延迟关闭。
- 空槽不可用，不应触发任何效果。

### 当前按钮

- `扔番茄`：从自己头像向目标好友播放番茄特效；通过通道 2 发给目标；本机扣 1000 点击。
- 右侧 `测试`：仅在本机模拟目标好友发来一条随机数字消息，用于检查未读气泡和聊天界面；不向对方联网发送。
- 互动有约 0.1 秒冷却，防止重复触发。

### 边界

- 互动环只属于桌上好友，不出现在自己头像或麻袋。
- 接收方只有在桌上放着发送者头像时才播放收到的互动。
- 点击反应不是互动按钮，不登记进互动目录。
- 新互动必须复用 `IOverlayInteractAction`、Catalog、Fx 和通道 2。

## 8. 麻袋界面

### 显示

- 位于右下角；存在桌上好友或袋内好友时显示入口。
- 收起时按钮显示“麻袋”及数量；展开时显示袋内列表。
- 袋内条目只显示 Steam 头像和名字。
- 不显示聊天摘要、未读红点、气泡、A/B、按键反应或互动按钮。

### 控件

- `麻袋 / 收起`：展开或折叠列表。
- 拖桌上好友到麻袋：收进袋内。
- 从袋内向桌面拖出：放到松手位置并保存。
- 桌上已满 30 人时拖出好友：必须先腾出一个桌上名额；现有分配逻辑负责收起一个好友。
- 袋内条目点击不打开聊天，也不触发玩法。

### 修改限制

- 用户未单独点名麻袋时，不改 `OverlayBagUi` / `OverlayBagItem` 功能。
- 新功能默认只接桌上头像，不能顺手加到麻袋。

## 9. 设置入口与设置面板

### 实现基线

- 设置界面已迁移到 `Resources/Prefab/UI/SettingsMenu.prefab`，运行时必须实例化该 Prefab，不再现场拼装主体界面。
- Prefab 的初始结构应与 `OverlaySettingsUi.Build()` 生成结果一致；`Build()` / `EditorPopulate()` 仅用于编辑器生成和结构对照。
- 设置面板以背景色和强调色两种主色派生完整视觉：风格 1 使用深色背景与粉色强调，风格 2 使用浅色背景与灰色强调；文字按背景明暗自动使用黑色或白色。两套共用方角面板和低圆角控件，并同步应用到头像聊天气泡、简易聊天和完整历史窗口。
- 游戏页提供“背景颜色”和“强调颜色”两行，点击后使用 RGB 滑条选择。确认任一自定义颜色后，风格显示“自定义”并将两种颜色持久化；再次点击风格行会切回深色/浅色预设，同时把两种颜色恢复为对应预设值。
- 标题左对齐并留出边距；游戏/系统页签使用文字，右上角关闭按钮和设置入口使用对应 Codicons，关闭按钮无底色。按钮只保留约 1–2 像素的视觉圆角，开关文字高度约占按钮的一半。
- 标题约 14px、正文约 13px；页签、操作行及关闭按钮默认透明，悬停显示主题浅底，选中页签和开启状态只使用低透明度强调色，不显示大块实色按钮。
- 设置面板主体保持固定紧凑高度并使用 1:1 像素渲染，宽度为原始设计的 0.7 倍；游戏/系统页切换时窗口尺寸不变化。设置入口大小不变。
- 其他界面暂不因本次迁移而改造，后续逐个确认、逐个切换到 Prefab。

### 入口

- Codicons 齿轮设置按钮只跟随自己头像，和头像下方点击数对齐并放在数字右侧，不能超出头像图片宽度，不显示“设置”文字。
- 点击设置按钮打开，再次点击同一按钮关闭；悬停不再打开设置。
- 设置、聊天、动态形象和裁剪界面打开后，点击界面外空白区域关闭；点击界面内部不关闭。互动环继续按悬停规则打开和离开关闭。
- 打开设置时关闭好友互动环。
- `关闭`：关闭设置及其动态形象子窗口。

### “游戏”页

- `−`：整体头像缩放减少 0.1。
- `+`：整体头像缩放增加 0.1。
- 缩放范围 0.5–2.5；默认 1.0。
- `禁止拖动`：开时禁止桌上头像和麻袋条目拖动。
- `水平翻转`：只改变自己的头像朝向。
- `按键图标`：控制是否显示/同步按键图标。
- `界面风格 1 / 2`：点击在两套设置主题之间切换，不显示主题名称。
- `背景颜色 / 强调颜色`：打开 RGB 颜色选择器；确认后启用自定义主题。
- `动态形象`：只显示当前启用状态，不是独立开关。
- `设置动态图`：打开 A/B 动态形象窗口。
- `复位头像位置`：恢复当前桌上头像默认排列并保存。
- `复位缩放`：恢复 1.0。

### “系统”页

- `始终置顶`：控制透明窗口置顶，默认开。
- `开机自启`：控制 Windows 登录后自动启动。
- `显示器`：下拉选项按当前连接数量显示 `1 / 2 / 3...`，选择后把透明桌面窗口切换到对应屏幕；选择写入现有用户设置。
- `退出游戏`：退出 CrazyChat。

用户可改设置统一保存在 `OverlayUserSettings` / `overlay_prefs.json`，不要另建设置系统。

## 10. A/B 动态形象窗口

### 显示

- 两个图槽：`闲置图 A`、`动态图 B`。
- 两张图都有效才启用；缺任意一张时继续使用 Steam 头像。
- 状态文字明确显示“已启用”或“需设置两张图后才会启用”。

### 控件

- `闲置图槽`：选择 A 图，然后进入方形裁剪。
- `动态图槽`：选择 B 图，然后进入方形裁剪。
- `清除`：删除 A/B 两张图并取消动态形象，头像回 Steam 图。
- `关闭`：关闭动态形象窗口。

### 图片规则

- 接受系统能读取的 PNG/JPG 图片。
- 保存前统一转 PNG；最长边不超过 256；单张不超过 200KB，超出时自动缩小。
- 图片和版本变化后自动同步给符合条件的桌上好友。

## 11. 方形裁剪界面

### 操作

- 拖动画面：移动裁剪位置。
- 鼠标滚轮：缩放图片。
- `缩小` / `放大`：缩放图片；按住可持续缩放。缩小下限为图片铺满方形裁剪框（不露黑边），放大上限约 4 倍。
- 不提供裁剪窗口本身的 `−` / `+` 缩放。
- `取消`：放弃本次选择，返回动态形象窗口。
- `确认`：输出方形裁剪图，保存到刚才选择的 A 或 B 图槽。

## 12. 会话提示界面

- 本机已运行一份 CrazyChat，再启动时显示“CrazyChat 已在本机运行”，随后退出后开的实例。
- 同一 Steam 账号在另一设备后开游戏时，先开的实例显示“已在其他设备登录 CrazyChat”，约 2.5 秒后退出。
- 只在别处登录 Steam、但没开本游戏，不触发退出。
- Steam 云不可用时，跨设备顶号可降级失效；本机单实例仍保留。

## 13. AI 修改前检查

- 需求对象是桌上头像还是麻袋？未点名麻袋，一律只做桌上头像。
- 新控件应放进哪个现有界面？优先扩展现有 `*Ui`，不要新建平行界面。
- 按钮点击后的打开、返回、关闭状态是否符合本文？
- 聊天是否仍走通道 1？互动/A/B/点击同步是否仍走通道 2？
- 是否误加了离线、云端、房间、匹配或麻袋玩法？
- 是否把设置写进现有用户设置，把策划数值写进 `OverlayConfig`？
