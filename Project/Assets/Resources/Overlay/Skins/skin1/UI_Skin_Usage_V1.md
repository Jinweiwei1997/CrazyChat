# UI Skin Resource Contract V1

Each skin must provide the same PNG filenames. All sprites use transparent backgrounds; text is rendered with TMP.

## Common window
- Window_BG.png — general window background, 9-slice.
- Window_Border.png — general window border overlay, 9-slice.
- Header_BG.png — title-bar background, 9-slice.
- Content_BG.png — inner content background, 9-slice.
- Divider_H.png / Divider_V.png — horizontal / vertical separators.

## Main menu entry
- MenuItem_BG.png — collapsed/default entry background.
- MenuItem_Active_BG.png — entry background while its submenu/panel is open.
- MenuItem_Icon_Settings.png — settings entry icon.
- MenuItem_Icon_Chat.png — chat entry icon.
- MenuItem_Arrow.png — optional submenu arrow.

## Settings panel
- Settings_Panel_BG.png — settings panel background, 9-slice.
- Settings_Panel_Border.png — settings panel border, 9-slice.
- Settings_Title_Icon.png — icon beside the Settings title.

## Buttons
- Button_BG.png — generic button background, 9-slice.
- Button_Icon_OK.png — confirm/apply icon.
- Button_Icon_Back.png — back/cancel icon.
- Close_BG.png — close-button background.
- Close_Icon.png — close X icon.

## Slider
- Slider_Track.png — slider track, 9-slice horizontally.
- Slider_Fill.png — filled portion, 9-slice horizontally.
- Slider_Handle.png — draggable handle; do not stretch.

## Toggle
- Toggle_BG_Off.png — off-state base.
- Toggle_BG_On.png — on-state base.
- Toggle_Knob.png — moving knob; do not stretch.

## Dropdown
- Dropdown_BG.png — current-value field, 9-slice.
- Dropdown_Arrow.png — dropdown arrow.
- Dropdown_List_BG.png — expanded list background, 9-slice.
- Dropdown_Item_Hover.png — highlighted list item, 9-slice.

## Chat
- Chat_Panel_BG.png — chat panel background, 9-slice.
- Chat_Panel_Border.png — chat panel border, 9-slice.
- Chat_Header_BG.png — chat title-bar background, 9-slice.
- Chat_Header_Icon.png — chat title icon.
- Bubble_Self.png — own-message bubble, right aligned, 9-slice.
- Bubble_Other.png — other-message bubble, left aligned, 9-slice.
- Bubble_System.png — centered system-message background, 9-slice.
- Input_Area_BG.png — background of the whole bottom input area, 9-slice.
- Input_BG.png — actual text input field, 9-slice.
- Send_BG.png — send button background.
- Send_Icon.png — send icon.
- Scrollbar_Track.png — chat scrollbar track.
- Scrollbar_Handle.png — chat scrollbar handle.
- Unread_Dot.png — unread notification dot.
- Unread_Badge_BG.png — unread-count badge background; number uses TMP.
- Corner_Decoration.png — optional skin-specific corner decoration.
